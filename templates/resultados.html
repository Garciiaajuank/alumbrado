PLANIFICACIÓN

Productos esperados

Entregables proyectados al inicio del semestre para dar respuesta a la problemática de gestión energética y mantenimiento del alumbrado público.

  • • Prototipo electrónico funcional (Maqueta IoT): Circ circuito a escala capaz de censar variables eléctricas y conmutar el estado de las luminarias.
  • • Modelo de datos transaccional (OLTP): Base de datos relacional normalizada en SQL Server para almacenar el inventario y lecturas operativas.
  • • Almacén de datos y flujo ETL (OLAP): Esquema multidimensional estrella alimentado mediante un paquete automatizado en SSIS.
  • • Plataforma web de monitoreo: Aplicación centralizada desplegada en la nube para visualizar en tiempo real el comportamiento de la red.

Soluciones desarrolladas, integradas y validadas satisfactoriamente dentro del ecosistema tecnológico del proyecto.

Conclusiones y evaluación del proyecto

Análisis final del cumplimiento de metas, limitantes técnicas superadas y proyecciones futuras para la optimización del sistema.

Cumplimiento de Objetivos

Se cumplieron a cabalidad los objetivos generales y específicos planteados en el PGC. Se estructuró un ciclo completo de ingeniería de datos que abarca desde la captura física de variables con IoT hasta la explotación analítica en un Data Warehouse, integrando interfaces web modernas y escalables.

Limitaciones Técnicas

Durante el desarrollo se presentaron restricciones de procesamiento asociadas al volumen masivo de registros (más de un millón de filas) en entornos locales, lo cual exigió optimizar las consultas T-SQL, los índices en el motor relacional y la configuración de memoria en los flujos de SSIS.

Oportunidades de Mejora y Proyección

Como evolución natural del proyecto, se proyecta la integración de modelos de Machine Learning predictivo para el mantenimiento preventivo de luminarias basado en series temporales, así como la conexión directa de la API de Flask con servicios de bases de datos en la nube para telemetría en tiempo real.
